# password-generator-java
This is a simple Java-based Password Generator that allows users to create secure passwords based on their preferences. The generated passwords can be saved in a text file for later use.

**✨ FEATURES**
- define your desired password length
- choose to include special characters or not
- uses a secure random function for strong passwords
- saves the generated passwords to generated_passwords.txt

**🙉 USAGE**
1. Compile the program: javac PasswordGenerator.java
2. Run the program: java PasswordGenerator
3. Follow the prompts to set your password preferences

**📍REQUIREMENTS: Java 8 or higher**
(the program uses SecureRandom, which was improved in Java 8 for better cryptographic security)
